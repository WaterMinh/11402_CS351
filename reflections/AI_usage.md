# AI Usage Throughout This Course

## Overview

During this course, I used AI as a development assistant rather than a replacement for programming. AI helped improve my productivity, but I was still responsible for understanding, implementing, testing, and verifying every solution.

---

## How I Used AI

### 1. Brainstorming

AI helped generate ideas for

- project structure
- software architecture
- README organization
- documentation layout

---

### 2. Learning

AI was used to explain

- Git workflow
- Scrum process
- Jira backlog
- branching strategy
- software testing
- GitHub Actions
- software engineering concepts

---

### 3. Programming Support

AI assisted with

- explaining C++ syntax
- debugging compiler errors
- suggesting algorithm improvements
- code refactoring
- improving readability

The final implementation was always reviewed and modified before being committed.

---

### 4. Testing

AI helped design

- test plans
- unit test structure
- edge cases
- helper functions
- GitHub Actions workflow

I verified every test manually before using it.

---

### 5. Documentation

AI assisted in writing

- README files
- weekly lecture notes
- project documentation
- presentation materials

All documentation was reviewed and edited to match the actual implementation.

---

## AI Usage Principles

Throughout this course I followed several principles.

- Understand the code before using it.
- Verify every AI-generated solution.
- Test every implementation.
- Never copy code without understanding it.
- Use AI to improve productivity instead of replacing learning.

---

## Reflection

The biggest lesson I learned is that AI is a powerful engineering assistant, but software engineers still need to understand system design, debugging, testing, and decision making.

AI can generate code quickly, but engineers are responsible for correctness, software quality, and the final product.
