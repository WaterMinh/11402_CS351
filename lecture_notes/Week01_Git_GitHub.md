# Week 01 — Git and GitHub

## Topic
Introduction to Git, GitHub, repositories, commits, and version control.

## Key Concepts
- Git is used to track changes in source code.
- GitHub is used to store repositories online.
- A repository contains project files and commit history.
- Commits record the development process.
- Good commit messages help explain what was changed.

## What I Practiced
- Creating GitHub repositories.
- Preparing a course repository.
- Organizing project files.
- Writing README documentation.
- Understanding how Git tracks file changes.

## Reflection
This week helped me understand that software engineering is not only about writing code. Version control is important because it records the process of development and makes the project easier to manage.
