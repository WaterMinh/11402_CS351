# Week 04 — Where Do Engineers Survive in the Age of AI?

## Topic
The role of engineers in the age of AI.

## Key Ideas
AI is changing the role of engineers, but it is not completely replacing them.

Engineers who only follow instructions are easier to replace. However, engineers who can build real products, understand systems, solve real-world problems, and continuously learn new tools will still be valuable.

## Important Points
- Build real projects, not only assignments.
- Learn how to deploy and run systems in production.
- Experience real problems such as bugs, failures, and debugging under pressure.
- Contribute to open source to learn collaboration.
- Read and understand other people's code.
- Focus on practical skills, not only theory.
- Learn continuously and adapt to new tools like AI.

## Personal Reflection
This lecture changed my understanding of software engineering. I realized that engineers should not only write code, but also build complete systems and solve real problems.

AI can help with development, but engineers still need judgment, system understanding, debugging ability, and product thinking.
