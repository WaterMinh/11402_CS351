# Week 02 — Scrum and Jira

## Topic
Scrum, Jira backlog, sprint planning, user stories, tasks, and workflow.

## Key Concepts
- Scrum is a software development framework.
- Jira is used to manage product backlog, sprint, and tasks.
- A product backlog contains user stories and tasks that need to be completed.
- Tasks move through workflow stages such as To Do, In Progress, In Review, and Done.
- A sprint is a planned period of work.

## Class Practice
We practiced how to create a project backlog in Jira.

Example project topic:
Student Grade Calculator

Main user stories:
- Input student information
- Calculate grade result
- Display final result

Under each story, subtasks can include:
- Design plan
- Implementation plan
- Code implementation
- Test plan

## What I Learned
I learned how to break a software project into smaller manageable tasks. Jira makes it easier to track progress and understand what still needs to be completed.

## Reflection
Before this class, I mostly thought about coding directly. After practicing Scrum and Jira, I understood that planning and task management are also important parts of software engineering.
