# Week 03 — Branch and Merge Workflow

## Topic
Git branch, merge, and development workflow.

## Key Concepts
- A branch allows developers to work on a feature without directly changing the main branch.
- After finishing the work, the branch can be merged into main.
- Pull requests help review changes before merging.
- Merge workflow provides evidence of collaboration and development progress.

## What I Practiced
- Creating branches for Jira tasks.
- Checking branches in VS Code.
- Making commits for each task.
- Pushing changes to GitHub.
- Merging completed work into the main branch.

## Example Workflow
```text
Create Jira Task
↓
Create Branch
↓
Implement Feature
↓
Commit Changes
↓
Push to GitHub
↓
Create Pull Request
↓
Merge to Main
