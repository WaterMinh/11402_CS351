# Project B — CSV Database and Query Engine

## Goal

Build a lightweight database system using CSV files.

---

## Features

- Load CSV
- Parse records
- Store data in memory
- SELECT *
- SELECT columns
- WHERE filtering
- Interactive console

---

## Query Examples

```
SELECT * FROM students

SELECT name, grade FROM students

SELECT name FROM students WHERE major=CS
```

---

## Testing

Interactive testing

Example scenarios

- Load CSV
- Display all records
- Select specific columns
- Apply WHERE condition
- Invalid query
- Exit program

---

## Learning Outcomes

- File I/O
- CSV Parsing
- Data structures
- Query processing
